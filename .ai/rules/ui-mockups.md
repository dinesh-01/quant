# Ui Mockups

## Static UI mockups live under public/
The HTML mockups are at public/ui-mockups/ so Laravel Cloud and artisan serve can serve them as static files. Do not put this folder back at the repo root — that path is not web-accessible. After a move, the production URL is /ui-mockups/index.html.
