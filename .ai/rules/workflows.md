# Workflows

## CI must provision two MySQL databases

The suite runs on MySQL, never SQLite: the specification tree loads through recursive CTEs and the audit tests assert against JSON columns, which MySQL reorders the keys of. Any pipeline therefore needs a MySQL 8 service and two databases — `quanta`, which `composer setup`'s `artisan migrate --force` targets from `.env.example`, and `quanta_test`, which `phpunit.xml` pins for the suite. The service container creates the first; a step with the mysql client creates the second. Run `composer setup` before `composer ci:check`: `types:check` is `tsc --noEmit` and the Wayfinder output it type-checks against (`resources/js/actions`, `resources/js/routes`) is gitignored and only generated by `npm run build`.
